# NumPy Statistical Analysis

This project performs statistical analysis of a numerical dataset using Python and NumPy. It calculates important statistical measures and identifies basic patterns in the data.

## Objective

The objective of this project is to practice applying NumPy statistical functions to numerical data and understand the distribution and variation of the dataset.

## Tools & Technologies

- Python
- NumPy
- Jupyter Notebook
- GitHub

## Dataset

A Student Performance Dataset containing students' marks out of 100 is used for analysis.

## Statistical Analysis

The following statistical measures are calculated:

- Mean – Average value of the dataset
- Median – Middle value of the dataset
- Standard Deviation – Measures variation in the data
- Minimum – Lowest value
- Maximum – Highest value

The project also:

- Compares the mean and median
- Checks for unusually high or low values
- Identifies important patterns in the dataset

## Key Observations

- The mean represents the average student marks.
- The median represents the middle mark.
- The mean and median are relatively close.
- Standard deviation shows how much the marks vary from the average.
- Minimum and maximum identify the lowest and highest marks.
- No extreme outlier is detected using the ±2 standard deviation check.
